Convexity in Optimization

The Critical Distinction Between Tractable and Intractable Problems

The Fundamental Principle

A function is jointly convex if, viewed over the full product space of all variables simultaneously, it satisfies the convexity inequality. When this holds, any local minimum is a global minimum, and you can apply joint optimization methods with guarantees of convergence to the global optimum.

When the objective is non-convex in the joint space but convex in each variable separately (biconvex or multi-convex), you're stuck with alternating minimization. You get convergence to a stationary point at best, not a global optimum.

Jointly Convex ✓

  • Every local min = Global min
  • Gradient descent converges
  • One-shot solution
  • Polynomial-time complexity
  • No initialization sensitivity

Biconvex ⚠

  • Convex in each variable alone
  • NOT jointly convex
  • Alternating minimization required
  • Converges to stationary point
  • Initialization matters!

Non-convex ✗

  • Multiple local minima
  • No convergence guarantees
  • Requires global search heuristics
  • Generally NP-hard
  • Extremely sensitive to init

The Optimization Hierarchy

Property Method Guarantee Complexity
Jointly Convex Gradient descent, Newton's method, Interior-point Global Optimum Polynomial time
Biconvex Alternating minimization, Block coordinate descent Stationary Point Depends on initialization
Non-convex Local search, Simulated annealing, Genetic algorithms No Guarantees NP-hard (generally)

How to Test for Joint Convexity

The Hessian Test

For a function f(x, y), compute the Hessian matrix:

H = [∂²f/∂x² ∂²f/∂x∂y] [∂²f/∂y∂x ∂²f/∂y² ]

Jointly Convex ⟺

Hessian is positive semidefinite (PSD) everywhere

All eigenvalues ≥ 0

Biconvex ⟺

Diagonal blocks are positive, but H is NOT PSD

Some eigenvalues < 0

Example: Testing f(x, y) = x² + y² + 4xy

# Compute Hessian H = [2 4] [4 2] # Eigenvalues λ₁ = 6 (positive) λ₂ = -2 (negative!) # Conclusion: NOT jointly convex # But ∂²f/∂x² = 2 > 0 and ∂²f/∂y² = 2 > 0 # So it's biconvex!

Real-World Applications

Linear Regression (Convex)

min ||Ax - b||²

  • Jointly convex in x
  • Closed-form solution exists
  • One-shot global optimum

Matrix Factorization (Biconvex)

min ||M - UV||²

  • Netflix prize problem
  • Requires ALS algorithm
  • Multiple initializations needed

Neural Networks (Non-convex)

Deep learning optimization

  • Highly non-convex
  • SGD with careful tuning
  • No global optimality guarantee
